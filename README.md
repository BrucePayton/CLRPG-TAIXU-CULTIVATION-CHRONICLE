# 太虚斗法录 · Taixu Cultivation Chronicle

一念御剑，一念问长生。

浏览器运行的复古像素修仙探索原型。采用传统 RPG 分区地图，靠近路标按 R 跳转；采集、交谈与遭遇战发生在当前地图中。旧落星台是可往返的独立地点，不以击败赤霄镇剑使作为游戏终点。

## 当前可玩内容

- **五张室外地图与一间室内**：听雨驿、雾松林、照石溪、残星原、落星台，以及可进出的听雨药庐，共 10 个出口（5 对往返连接）；当前地图小地图与 Tab 路线图。基础四图仍为过渡布局。
- **原地遭遇**：苔角鹿逃避接近者，岩背豕先警告再守领地，暮影狼追击并在重伤时逃离；岩石阻挡视线与弹道。镇剑使默认中立，可交互切磋。
- **探索闭环**：采灵草与灵砂、交付药师委托、阅读三座石碑、营火休整。对手生命与资源领取状态在本次世界中保留。
- **修炼技艺**：回元丹、聚气丹、减速伤害阵、木灵傀儡护卫与自愿合修调息。
- **战斗基础**：玉剑三连斩、闪身残影、持续护身、御剑拖尾与十八剑阵；与旧场景复用角色、剑弧、护罩、符火表现。落星台切磋前需确认，双方点到即止；只有主动重赛才恢复镇剑使生命，首次胜利赠丹不重复领取。
- **自创术式**：四元素任选一至两种，搭配三种形态和三种修饰，共 90 种合法配置；六种双元素融合有派生名称与规则。编辑器提供即时特效预览。
- **动态光照**：软件二维光线遮挡、法术彩光与岩石阴影，支持关闭 / 柔光 / 光线阴影。
- **暂停**：Esc 暂停；离开窗口自动暂停；编辑术式和打开工坊时暂停。

新地图混用程序化布局与 ComfyUI 候选，部分素材仍有灰边、裁切及动画缺陷，未通过最终美术验收。后续使用 Aseprite 修整与 Blender 辅助布局，见[策划](docs/design/GAME-DESIGN-V1.md)。世界状态跨地图保留，但仅在当前页面内存中，**刷新或关闭页面会重新开始**。

## 快速开始

需要 Node.js `20.19+`（20.x）或 `22.12+` 和 npm。推荐桌面浏览器、键盘与鼠标。

```bash
npm ci
npm run dev
```

打开终端地址，通常为 `http://localhost:5173/`，点击「步入山野」。

```bash
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

生产预览通常在 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，端口占用时以终端为准。这是本机地址，不是线上试玩站点。

游戏不需要启动 ComfyUI、SoundGenerated 或 AI 服务。字体使用 Google Fonts，离线时回退系统字体。

护身开启消耗 12 灵力，不自动到期；每次抵挡耗灵 4、减伤 75%，不足则破盾。开启前 0.19 秒可完美化解一次。御剑不免疫符弹和近身攻击；飞越溪流时不能在深水主动落地，耗灵殆尽会返回最近可落脚位置。

重伤后可返回营火继续本次探索，已采集资源、任务、碑文和对手状态不重置；这是原型恢复机制，不是完整死亡继承系统。

## 自创术式

`术式 = 1–2 个元素 + 弹道形态 + 修饰`

- 元素：玉 / 霜 / 火 / 雷。
- 形态：直射 / 三分 / 八方。
- 修饰：凝实 / 贯穿 / 扩散。
- 融合示例：玉＋雷 → 贯雷刃；霜＋雷 → 霜雷锁；霜＋火 → 蒸雾术。
- 特效由双方色彩、交织轨迹、冰晶、电弧、尾焰及融合轮廓组合，不是简单换色。
- 90 是合法配置数量，不是 90 套独立动画。配方越复杂，耗灵与冷却越高。
- 当前只有一个自创槽；尚无术式收藏库、任意技能嵌套融合或配方存档。

完整规则、成本公式及扩展边界见 [自创术式设计](docs/SPELLCRAFT.md)。

## 项目结构

```text
src/world-runtime.js   当前入口、输入、界面与固定步进循环
src/world.js           地图实体、生态行为、采集、战斗与修炼规则
src/world-art.js       地图、设施、魔兽、镜头与小地图绘制
src/spellcraft.js      配方编译、融合规则、弹道及组合特效
src/combat.js          共享近战时间轴与扫掠命中
src/art.js             主角、玉剑与镇剑使绘制
src/effects.js         通用战斗特效
src/boss-effects.js    赤霄符火特效
src/lighting.js        软件二维光线遮挡
src/audio.js           音乐切换与音效
src/duel.js            保留的旧单场斗法原型，非当前入口
src/game.js            更早的原型，非当前入口
tools/test-world.mjs   连续世界与自创术式测试
tools/test-duel.mjs    旧战斗及共享模块回归测试
public/               美术与音效静态资源
docs/production/      素材来源及生成记录
```

使用原生 JavaScript ES Modules、Canvas 2D、Web Audio 与 Vite。画面为 480×270 内部分辨率与最近邻放大，不要求素材统一 32×32。2.5D 是投影表现，不是三维引擎。

光照是 Canvas 软件二维射线求交，不是硬件 RTX、路径追踪或全局光照；新地图以岩石轮廓参与遮挡，没有角色自阴影、法线贴图或真实反射。

## 测试与限制

`npm test` 验证战斗、持续护身、资源扣除、任务幂等、重伤恢复、地形、生态、暂停、炼制、合修和 90 种术式配置，并覆盖 20 轮地图往返、跨图攻击隔离及切磋奖励幂等；`npm run build` 生成生产静态文件。实机检查范围见 [P1 记录](docs/design/P1-DELIVERY.md)。

测试以纯逻辑和模拟绘图上下文为主，不替代真实浏览器、长期平衡、性能或全地图人工验收。

2026-10-05 接入[听雨驿统一资产 V2](docs/production/camp-v2/DELIVERY.md)：按同一参考重制药庐、松树、医师与低对比石板，保留原主角/Boss/特效并校准碰撞与脚底。生成来源、Aseprite 整理及浏览器证据分别记录；小道具、草地与其他地图尚未统一，最终美术验收仍待审。

修复技能栏只能展示的问题：技能支持点击，剑阵/布阵在界面显示当前道意、材料、灵力和冷却，条件不足会给出具体原因。药庐门前按 R 进入，室内卧榻按 R 休整、丹炉旁按 B 炼制，门口按 R 返回；室内禁止御剑。[室内美术 V2](docs/production/lodge-v2/DELIVERY.md) 已替换墙地、卧榻和炼丹台占位图形，并接入家具排序与暖色灯光；最终视觉验收和家具交互动画仍待完成。

当前限制：

- 尚无跨刷新存档、完整 NPC 日程、交易系统、装备和境界成长。
- 生态是轻量状态机，障碍绕行尚无完整寻路；听雨驿样板有建筑/树干碰撞与遮挡，其余地图树木和屋舍仍主要为装饰。
- 三种魔兽已接入 [V3 单姿态素材与行为音效](docs/production/beasts-v3/DELIVERY.md)，野外松树共用营地版本。访问 `/beast-preview.html` 试听，音色仍待确认。灵兽、主角与镇剑使的完整逐帧动作以及部分设施美术仍待完善。
- 基础炼制为即时配方，没有品质、火候、失败率或复杂材料树。
- 阵法和傀儡各一类，合修为单名自愿同修 NPC 的非情色调息玩法。
- 法术直接命中会叠加元素状态；融合专属命中/残留效果仍待细化。
- 资源有限、不自动刷新；重伤恢复不会重新发放一次性奖励。
- 暂无手柄、触屏和键位重绑；没有配置在线演示站点。
