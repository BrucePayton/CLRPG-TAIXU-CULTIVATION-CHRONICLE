# 太虚斗法录 · Taixu Duel

一念御剑，一念问长生。

一款运行在浏览器中的修仙斗法动作游戏原型。以复古像素画风与 2.5D 俯视场景呈现云海之上的落星台：玩家扮演手持青珩玉剑的沈砚，与赤霄镇剑使对话、交锋，在御剑、护身与剑阵之间寻找破敌时机。

当前为**单场景、单 Boss 的可玩战斗原型**，具备「战前对话 → 战斗 → 胜负结算 → 再次挑战」流程，尚非完整修仙 RPG。

## 游戏特色

- **玉剑近战**：三段连斩与重斩，包含蓄势、挥剑和收招，伤害随剑锋扫过结算。
- **御剑飞行**：踏剑升空、加速移动、越过地面符火，灵力耗尽后自动落地。
- **持续护身**：太极护身持续减伤，开启瞬间可完美化解，护身期间仍可攻击和施法。
- **飞剑与剑阵**：三枚飞剑、十八剑环阵、连续拖尾、碎玉命中特效与收束冲击。
- **两阶段 Boss**：独立的青铜面具、赤黑袍形象，具有近身攻击、符弹和半血后的离火区域攻击。
- **动态光照**：玉剑青光、Boss 赤焰、法术光源与石柱遮挡阴影。
- **声音反馈**：战前与战斗音乐切换、生成式飞剑音效及 Web Audio 合成音效。

## 快速开始

需要 Node.js `20.19+`（20.x）或 `22.12+`，以及 npm。建议使用桌面浏览器、键盘与鼠标。

在项目根目录执行：

```bash
npm ci
npm run dev
```

打开终端输出的地址，通常为 `http://localhost:5173/`。点击「踏入试炼」开始对话，音频会在用户交互后启动。

构建并预览生产版本：

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

通常通过 [http://127.0.0.1:4173/](http://127.0.0.1:4173/) 访问；端口占用时以终端输出为准。这是运行项目的本机地址，不是线上演示地址。

运行游戏不需要启动 ComfyUI 或 SoundGenerated，生成结果已作为静态资产接入。页面字体使用 Google Fonts，无法联网时使用系统字体回退。

## 操作说明

| 操作 | 按键 | 效果 |
| --- | --- | --- |
| 移动 | `W A S D` | 沿战斗平台移动 |
| 瞄准 | 鼠标移动 | 调整面向及出剑方向 |
| 玉剑攻击 | `J` / 左键 | 三段近战连斩 |
| 太极护身 | `K` / 右键 | 开启或解除持续护身 |
| 闪身 | `Space` | 消耗 14 灵力，短暂闪避无敌 |
| 御剑诀 | `Q` | 消耗 26 灵力，发射三枚飞剑，冷却 2 秒 |
| 万剑归宗 | `E` | 消耗积满的 100 道意，释放十八剑阵 |
| 御剑飞行 | `F` | 切换升空与落地 |
| 推进对话 | `Enter` / `Space` | 四段对话结束后开战 |

页脚提供声音开关及「关闭 / 柔光 / 光线阴影」三档光照切换。

### 御剑与灵力

- 起飞至少需要 15 灵力，飞行每秒消耗 3 灵力。
- 满灵力、无施法及其他收支时，约可持续飞行 33 秒。
- 地面状态每秒恢复 7 灵力，命中敌人也会回复少量灵力并积累道意。
- 升至足够高度可躲避地火，但**不能免疫符弹与近身攻击**。

### 太极护身

- 开启消耗 12 灵力，不按秒耗灵、不自动到期，再次按键解除。
- 每次抵挡消耗 4 灵力，减少 75% 伤害；不足 4 灵力时护身破裂，本次承受原伤害。
- 开启后的前 0.19 秒可完美化解一次攻击，免受该次伤害并获得道意。
- 护身不会锁住后续攻击或移动，光罩随御剑高度升降；开启施法会中断当前挥剑。

以上为原型平衡参数，后续可能调整。

## 技术实现

使用原生 JavaScript ES Modules、Canvas 2D、Web Audio 与 Vite，无前端框架，不依赖游戏后端。

- **画面**：480×270 内部分辨率与最近邻像素缩放，素材没有统一 32×32 限制。
- **视角**：二维坐标投影和位置排序模拟 2.5D 俯视效果，并非真正的三维场景。
- **动作**：共享近战时间轴驱动程序化持剑动作、剑弧与扫掠命中，每次挥剑最多命中一次。
- **特效**：限制粒子与效果数量，支持剑气轨迹、阵纹、化解星芒和局部冲击。
- **光照**：软件二维射线与石柱轮廓求交，裁剪可见区域，再合成环境光贴图；最多选择 16 个光源，剑阵按每三剑一个光源采样。

「光线阴影」是 **Canvas 屏幕空间二维光线遮挡**，不是硬件 RTX、路径追踪或真实全局光照。目前仅四根石柱参与遮挡，不包含角色自阴影、材质反射、法线贴图或高度正确的投影阴影。柔光档保留动态照明但跳过遮挡求交。

## 测试与开发

```bash
npm test
npm run build
```

逻辑测试覆盖对话门控、御剑耗灵与落地、持续护身及破盾、近战延迟命中与取消、技能资源与冷却、Boss 转阶段、胜负重开、特效数量上限、光线求交及光照档位。

测试使用模拟 DOM 的 Node.js 环境，不代表已完成真实浏览器画面、音频、性能或长时间游玩验收。开发服务器中的 `/tools/effects-preview.html` 可独立预览攻击特效。

修改战斗后建议检查：对话前不能攻击；护身持续生效且不阻止出招；升空后地火与符弹判定不同；Boss 半血转阶段；胜负结算后可正常重开。

## 已知限制与后续方向

- 只有一个场景与一个 Boss，尚无修炼成长、装备、背包、多关卡或存档。
- 主角使用现有站立、行走图集和程序化持剑动作；Boss 主要为单体图像与程序动画，缺少完整攻击、受击、转向和死亡逐帧动画。
- Boss 招式组合与数值仍需打磨，御剑尚不是独立的空战系统。
- 暂无暂停、失焦自动暂停、键位重设、手柄和触屏操作。
- 加载提示、资源失败反馈、音量细分设置及浏览器自动化测试尚未完善。
- 美术风格与投影仍有不一致之处，光照采用简化遮挡而非物理渲染。

下一步优先完善角色动作、Boss 招式与战斗反馈，再扩展场景和成长系统。
