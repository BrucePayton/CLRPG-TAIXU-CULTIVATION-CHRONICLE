# 自创术式：组合、融合与特效派生 v1

## 当前已实现的配方结构

`术式 = 1–2 个不同元素 + 1 个弹道形态 + 1 个修饰`

在连续世界按 **V** 打开编辑器。编辑时暂停世界，可预览组合弹道、查看消耗并装备至自创栏；按 **5** 选用，**Q** 施放。不需要切换战斗场景。

第一版有 4 种单元素与 6 种无序双元素组合，再乘 3 种形态、3 种修饰，共 **90 种合法配置**。这是配置数量，不是 90 套完全独立制作的动画。

### 元素模块

| 元素 | 基础作用 | 特效语言 |
| --- | --- | --- |
| 玉 | 直接伤害 | 青玉轮廓、剑气光带 |
| 霜 | 命中后减速 2.5 秒 | 冰蓝轨迹、冰晶短棱 |
| 火 | 命中周围小范围波及 | 橙红宽尾焰、火光 |
| 雷 | 短暂失衡，较快弹速 | 紫白折线电弧 |

### 双元素融合

| 配方 | 派生名称 | 融合变化 |
| --- | --- | --- |
| 玉＋霜 | 碎冰玉刃 | 玉刃与冰晶共存，附带减速 |
| 玉＋火 | 流焰剑 | 玉刃带火尾，命中范围波及 |
| 玉＋雷 | 贯雷刃 | 玉刃与电弧交织，默认可穿透 2 个目标 |
| 霜＋火 | 蒸雾术 | 交织轨迹加蒸雾环，波及半径 35 |
| 霜＋雷 | 霜雷锁 | 冰晶、电弧与封印轮廓，失衡延长为 0.5 秒 |
| 火＋雷 | 雷火爆 | 雷火交织、尖角能量轮廓，波及半径 38 |

元素输入顺序不影响规则，配方会规范排序。第一版以属性继承和少量显式反应为主，不宣称已经模拟温度、导电、水汽或真实化学反应。

### 形态与修饰

形态：直射 1 弹、三分 3 弹、八方 8 弹。每弹伤害系数分别为 1、0.6、0.35；增加覆盖范围需付出更高耗灵与冷却。

修饰：凝实为基础；贯穿最多命中 3 个不同目标；扩散将波及半径设为 42。贯雷刃与贯穿取上限而非相乘。波及仅造成直接命中伤害的 40%，不会再递归触发波及或状态传播。

## 统一编译规则

- 耗灵：18＋元素附加值之和＋双元素附加 8＋形态附加＋修饰附加。
- 元素附加：玉 0、霜 3、火 5、雷 7。
- 形态附加：直射 0、三分 8、八方 18；修饰附加：凝实 0、贯穿 8、扩散 10。
- 冷却：2 秒＋双元素 0.7 秒＋形态附加（0 / 0.5 / 1.2）＋修饰附加（0 / 0.6 / 0.8）。
- 每弹基础伤害：单元素 24、双元素 29，再乘形态系数。角色成长增益另行乘算。
- 最大两元素、八枚弹道、三目标穿透；单个弹道记录已经命中的实体，不因持续重叠再次命中。
- 施法时复制配方到弹道。重新编辑只影响下一次施法，不改变已经飞出的法术。
- 禁止重复元素、未知元素或无效形态；资源不足不生成弹道、不扣资源。

当前强度数值是原型起点，并非经过完整平衡验收。多枚弹道可以命中同一目标，范围技能对密集敌群较强。

## 特效派生规则

不为每种配置准备一张专属图片，而是按配方合成：

1. 元素层决定色彩、轨迹、冰晶或电弧。
2. 双元素以两条相位相反的波动轨迹交织，保留双方特征。
3. 融合反应添加蒸雾、封印或尖角能量轮廓。
4. 形态层改变发射数量和方向，修饰层叠加扩散环。
5. 地图照明按元素颜色生成局部光源，仍受总预算限制。

编辑器与实战使用同一弹道绘制函数，预览不独立伪造效果。命中特效目前复用火焰/化解冲击，尚未为六种融合分别制作完整的命中、残留和环境反馈。

## 与探索系统的连接

- 炼丹：灵草与灵砂制造回元丹、聚气丹。
- 阵法：Z 消耗灵草与灵力布置八秒减速伤害阵，只自动作用于已交战对手。
- 傀儡：工坊制作后可用 X 召唤二十秒护卫，不自动攻击中立目标。
- 合修：完成药师委托后，在其身旁落地并安全调息三秒；移动、施法会中断。完成后恢复部分气血与灵力，增加六十秒地面回灵。为双方自愿的非情色修炼内容。

这些是基础闭环，并未实现丹药品质、阵眼网络、多型号傀儡、关系模拟或完整修炼境界。

## 后续可扩展但尚未实现

- 从术式收藏库选择多个已有技能，提取元素/形态作为输入；当前只有一个可编辑自创栏。
- 连锁、延迟引爆、护体环绕、地表场等新形态。
- 施放—命中—残留三段组合，但必须限制递归深度和触发次数。
- 配方发现、熟练度、术式命名与跨刷新存档。
- 融合反应专属命中特效、可交互地表与实战平衡测试。

不能仅因输入任意文字就生成无边界能力；新增模块必须同时实现规则、资源代价、特效、可解释预览和回归测试。
