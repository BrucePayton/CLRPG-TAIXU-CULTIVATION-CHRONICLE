# 剑阵、布阵与药庐入口修复

## 原因

- 技能栏原为 div，且父层 pointer-events:none，没有点击处理；鼠标点击不会调用技能。
- 剑阵在道意不足 100 时直接忽略输入，没有解释。初始道意为 0，因此初进游戏按 E 看不到任何反应。
- 布阵需要灵草 1、灵力 20、冷却结束，但界面没有独立技能按钮和条件状态；原错误信息笼统。
- 药庐只是外观和碰撞，没有入口/室内地图，无法通过走进贴图进入。

## 改动

- 技能栏改为真实按钮，鼠标、原快捷键与按钮的 Enter/Space 都走同一规则入口。空格在技能按钮聚焦时不会额外触发闪身。
- `arrayStatus` 为施放规则与界面提供共享条件；资源不足、冷却、目标缺失均有具体反馈。未降低成本或免费发放道意/材料。
- 剑阵不锁定未同意切磋的镇剑使；成功生成 18 柄剑并造成伤害。布阵明确反馈持续 8 秒，只伤害正在交战的敌人。
- 新增听雨药庐室内和一对 R 入口，采用已有地面材质/程序化功能布局。卧榻可恢复，丹炉旁可炼制；角色进门自动落地，室内不允许御剑。跨图清理效果并保留资源、采集和任务状态。
- 原 Boss 圆台、人物与法术表现文件未修改。

## 验证

- `npm test`：六张地图、十出口、20 轮换图、营地可达性、旧表现哈希；新增 `test-arrays-room.mjs` 覆盖资源扣除、冷却、阵法伤害、剑阵伤害、非交战 Boss 保护，以及入室、休整、制作和返回。
- `npm run build`：通过。
- `review-arrays-room.mjs`：正常键鼠（不注入玩家状态）验证 E 提示、Z 缺材料、步行采草、点击布阵、键盘冷却反馈、步行进屋、休整、打开丹炉界面、出门返回。记录见 [checks.json](./checks.json)。
- 满道意剑阵的成功伤害由领域测试验证，本轮没有宣称完成真实浏览器内积攒 100 道意的战斗全流程。
- 室内仍是功能性美术，不是此前全场景样板的成品室内资产；本轮未改变音乐文件，未推送远程。
