# 灵兽与野外松树 V3

已接入的预览候选；审美批准与音效听感验收尚未完成，没有推送远程。

## 来源

内置 image_gen 参考旧物种及营地 V2 同尺度板生成鹿、豕、狼。提示词见 prompts.json，原图在 source/。Aseprite 执行 tools/prepare-beasts-v3.lua：alpha 裁边、最近邻缩放、二值透明、两像素留边和脚底注册，保留 .aseprite。这不是手工逐像素精修或完整动作图集。

尺寸为 40×56、61×44、81×43（含留边），映射 src/beast-assets.js。不改碰撞、生命值、AI。野外 pine 共用 camp-v2/pine.png，保留 91 像素高度。受保护的旧 Boss、主角、闪身与斗法特效未修改。

## 音效

本地 SoundGenerated MLX Small SFX，seed 1041/1042/1043，非振荡器替代。请求、结果、模型版本在 audio/，哈希见 manifest.json。

生成 2 秒 → 从 0 裁切 2 秒 → 15ms 淡入/120ms 淡出 → 单声道 PCM16 WAV。目标 -24dBFS RMS，非循环，峰值低于 -1dBFS。机械检查通过，未调用批准接口。

鹿逃离、豕示警/蓄势、狼追击/蓄势时触发，单体冷却分别 8/7/6 秒。180 世界单位内距离衰减；同物种间隔 3 秒、全局间隔 0.8 秒、最多两路。静音、暂停、对话、死亡、切图和页面隐藏停止兽声；未加载采样丢弃事件，不补播过时警告。

## 验证与限制

- npm test 与 npm run build 通过；旧战斗、地图、药庐、布阵回归保留。
- tools/review-beasts-v3.mjs 真实浏览器验证鹿受惊、狼追击音频调用、三条 WAV 解码和资源加载。使用开发起点，不是全流程游玩。
- runtime/ 同尺度板与场景截图已检查：透明背景、轮廓可辨，松树共用营地版本。
- 完整主观试听及场景混音听感仍待确认。播放/解码成功不等于音色合格；访问 /beast-preview.html 逐条试听。
- 灵兽仍为单姿态，行走/攻击/受击动画未完成；野外地表、矿物、路牌和其他地图仍待优化。
- 未引用私人音乐。公开发布前需复核模型输出再分发条件；代码 MIT 不自动覆盖素材。
