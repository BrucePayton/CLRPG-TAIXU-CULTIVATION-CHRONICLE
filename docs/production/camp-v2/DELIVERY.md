# 听雨驿统一资产 V2

## 本轮范围与状态

依据用户在第二轮风格候选之后的“继续”，推进营地最小资产组，而非重新设计全游戏。整体方向继续制作不等于用户已经验收每张成品。

已生成并接入预览：药庐、松树、医师 12 帧图集、石板纹理。运行时路径位于 `public/assets/camp-v2/`。原 `camp-v1` 文件及历史验收记录未覆盖，旧主角、Boss、圆台和战斗特效保持原样。

候选生成、同尺度检查、运行时接入与浏览器回归均已完成。最终主观美术验收仍为待审，不声称所有地图已统一。

## 实际制作链

1. 内置 image_gen 分别生成四类素材；完整提示词见 [PROMPTS.md](./PROMPTS.md)。本轮未调用 ComfyUI / Blender，不将输出冒充这些工具的结果。
2. 参考为上一轮 `style-v2/candidate-02.png`；医师另参考原主角图集以对齐成年比例和服装细节密度。
3. Aseprite 批处理脚本 [prepare-camp-v2.lua](../../../tools/prepare-camp-v2.lua) 检测真实 alpha，按边界裁切、等比采样、增加透明边距；医师采用统一缩放率并固定脚底。不是逐像素手绘精修，不把降采样当成原生像素资产认证。
4. 地面单独使用平均采样、受限蓝灰色阶、对边像素配准，压低高频纹理与平铺接缝。透明精灵仅二值化 alpha，没有按颜色抠掉浅色衣袍。
5. 保存可编辑 `.aseprite`、生成原图、运行时 PNG、来源及哈希 [manifest.json](./manifest.json)。

| 资产 | 实际尺寸 | 注册与用途 |
| --- | --- | --- |
| 药庐 | 282×150 | 包含台阶，脚底基点 y=148；扩大基础碰撞至匹配主体宽度 |
| 松树 | 100×104 | 脚底基点 y=102；沿用地图树高变化和遮挡渐隐 |
| 医师 | 576×58 | 12 个 48×58 格；身体 50–51 高，统一足底 y=55 |
| 石板 | 96×96 | 不透明、重复铺装；庭院与道路共享纹理 |

医师包含南/北/西/东待机和眨眼槽位，以及四个正面辨药姿势。北向“眨眼”复用北向待机，不伪称独立动画；尚无新增行走动画。

## 接入与修正

- `camp-assets.js` 显式绑定固定资产路径，不扫描最新候选；本地加载，不依赖生成服务在线。
- `world-assets.js` 增加按绘图上下文缓存的地面纹理图案，尚未载入时仍有原静态回退。
- 庭院延伸至药师交互区，地面与道路采用同一石板。移除新药庐已经自带的重复程序化台阶。
- 建筑变宽后同步扩大地基碰撞，移动两棵邻树；遮挡渐隐宽度随建筑更新。地图边界、出口、玩法和奖励没有改变。
- 旧 V1 记录器增加版本保护，避免后来误运行时覆写历史来源说明。

## 检查与证据

- `npm test`：逻辑、场景、地图往返和营地测试通过；包含全交互点可达、固定脚底、透明边缘、地面平铺边界、新资产来源哈希、旧英雄/Boss/特效保护哈希。
- `npm run build`：通过。
- 浏览器回归使用正常键盘输入，外部 HTTPS 请求屏蔽：营地进入、辨药画面、药师交互、御剑及持续护身、雾松林出口与返回均通过。旧圆台通过标明的开发入口检查，对话及飞行护身可用；不冒充从营地走到圆台的完整游玩。
- [checks.json](./runtime/checks.json) 记录浏览器结果；[camp-arrival.png](./runtime/camp-arrival.png)、[camp-healer.png](./runtime/camp-healer.png)、[camp-return.png](./runtime/camp-return.png) 为真实运行画面。
- [同尺度排版检查](./index.html) 与 `same-scale.png` 是独立素材排版，不是实机证据。

复现：

```sh
/Applications/Aseprite.app/Contents/MacOS/aseprite -b --script-param root="$PWD" --script tools/prepare-camp-v2.lua
node tools/record-camp-v2.mjs
npm test
npm run build
CAMP_REVIEW_DIR=docs/production/camp-v2/runtime PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node tools/review-camp-sample.mjs
```

浏览器脚本要求本地开发服务 `http://127.0.0.1:4174/` 已运行。`PLAYWRIGHT_MODULE` 指向本机安装，不含包的下载步骤。

## 剩余不足与下批顺序

1. 营地灯柱、药架、药圃和草地仍为程序化表现，精细度落后于新建筑；因此当前只是主资产组统一，不能称整张地图全部完成。
2. 松树只有一种轮廓，多棵重复明显；后续需同风格变体，而非再换一套画风。
3. 屋顶高光与细叶仍略密，需继续在 480×270 实机尺寸下做像素簇精修；场景未达到概念图全部细节。
4. 其他地图、魔兽未在本轮扩批；应先补齐营地小道具，再沿同一标准扩展。
5. 未改变音乐，未重新进行音色主观验收；未做全机型性能或长期游玩验收。
6. 未提交或推送远程。源代码 MIT 不自动覆盖美术；本轮未进行新的公开分发审查。
