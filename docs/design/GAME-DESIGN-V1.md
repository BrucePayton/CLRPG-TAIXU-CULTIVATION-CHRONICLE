# 太虚修行录：分区关卡与玩法策划 v1

日期：2026-10-01

状态：**研究后的设计草案，待确认；不是已实现版本。**
依据：[本地研究记录](RESEARCH-V1.md)。K1–K7 是知识库灵感；以下地图、任务、机制、预算均为本项目原创设计。

## 1. 不改变的核心

- 复古像素、2.5D 俯视、主角持玉剑；取消统一 32×32 限制，按角色、建筑和地块用途定尺寸。
- 传统 RPG 分区地图，通过现场出口进入另一地图；**遇敌不会自动切换地图**。
- 旧落星台完整成为独立地点：云海、圆台、八卦纹、石柱、台阶、旧 Boss 身份与配色继续保留。
- 赤霄镇剑使属于普通切磋内容，不是唯一战斗模式、主线门槛或最终结局。
- 闪身残影、玉剑剑弧、护身法术、御剑拖尾、剑阵和赤霄符火共用表现规范，不因地图不同换一套技能。
- 防御仍是持续生效的护身法术；御剑维持低耗灵气。此次策划不擅自重调既有数值。
- 不迁移到 Godot 或 3D 引擎。现有浏览器 Canvas 运行时继续使用；Blender 仅作开发期资产辅助。
- 先形成可检验的小闭环，再增加地图和系统；工具生成成功不等于视觉验收通过。

## 2. 玩家体验与循环

目标是让玩家觉得“我观察了这个地方，并用自己准备的手段解决了问题”。

准备丹药 / 阵具 / 术式 → 进入区域 → 读地形与习性 → 选择绕行、解阵、协作或斗法 → 获取材料与见闻 → 返回制作与试法。

首个切片测试时长目标 20–30 分钟，后续第一章目标 45–60 分钟；均为待实测目标，不是目前已有内容时长。每张地图至少一个特色互动、一个可记住的地标、一个有代价的选择。避免大面积空地与换颜色的重复杀怪任务。

                 │

                 │               │
            断机工坊（新增）     残星原 ─── 落星台（旧 Boss 场景）

线为双向现场出口，不是世界地图点击传送。首批只打通听雨驿—雾松林—照石溪—残星原—落星台，新增支区按后续阶段加入。

| 地图 | 体验职责与地标 | 特色选择 / 非战斗方案 | 收益与再次拜访理由 |
| --- | --- | --- | --- |
| 听雨驿 | 安全准备区，药庐与路标 | 查看委托、辨药、稳定炼丹或亲自控火 | 丹方、传闻、材料交换；不靠等待 NPC 刷新卡住任务 |
| 雾松林 | 习性教学，倒木、兽径、豕巢 | 观察鹿群找草；避开巢区或引开守巢豕 | 灵草、足迹笔记、阵旗木材；学习技能后开支路 |
| 照石溪 | 环境术式，双桥与浅滩 | 步行走桥、低耗御剑或短暂凝霜渡水 | 凝露、救助线索、元素反应试验点 |
| 残星原 | 残碑解读，破损星盘与通往圆台的山门 | 阅读三碑后校正星盘，或清理非生命守卫 | 开回程捷径、融合心得；不是强制击杀镇剑使 |
| 落星台 | 熟悉的旧场景，稳定战斗基准 | 入场先交谈；观察招式、请求切磋或离开 | 一次心得奖励，可选复练；认输结束，不作为死亡处理 |
| 听雨洞府 | 小型生活与制作据点，试法石、药圃 | 先修丹炉还是先修阵案；免费基础休整 | 种植、装备方案、术式试验；不首批做大型装修系统 |
| 断机工坊 | 傀儡指令与机关，断电运轨 | 修复可操作傀儡，守点压机关；也可亲自绕路 | 单傀儡模块与工匠线索；战斗与解谜共享同一单位 |
| 回风阵谷 | 阵法综合应用，三阵枢与风道 | 观察供能→断线，或改向借阵；强攻代价更高 | 阵式变体、区域捷径；不单纯加 Boss 血量 |

尺寸先按主角现有约 51 逻辑像素身高与 480×270 视口做可达白盒；不沿用当前世界竖条区域宽度作为最终独立地图尺寸。落星台保留原构图比例，普通地图可内部滚屏。

### 地图跳转契约

- 使用稳定 mapId、entityId、exitId 和 spawnId；不再靠全局 x 坐标推断地图。当前坐标分区方案仅过渡草稿。
- 路标显示目的地；靠近按 R 后短淡出/淡入，到达明确安全落点。长按、重复事件不得连跳。
- 每条出口必须有返回路线，重要入口不在敌人攻击范围内；飞行不能越过地图边界，仍需出口。
- 离开地图终止本图弹体、预警与临时伤害；不把旧弹体带去新图。护身开关、角色资源与已解锁能力保持。
- 傀儡跟随到安全位置；阵法留图还是结束必须有一致规则，首批明确结束临时战斗阵法。
- 敌人生命、是否认输、采集、机关、任务奖励、捷径状态跨图保留。离图不回血、不复活、不重复发奖。
- 首批离图区域冻结即时战斗模拟，不模拟全世界 NPC 战争；再次进入按保存状态恢复到安全可读状态。
- 菜单、加载、失焦暂停资源结算。后续本地存档需版本、完整性检查和旧版本迁移；当前页面刷新会重置的问题仍未解决。

## 4. 三条贯穿任务链

### A. 药香引路：观察与炼丹，不强制杀怪

药师给出采药线索 → 观察苔角鹿的进食点 → 安全采集 → 溪边取得凝露 → 回驿炼制舒息散 → 治疗受惊灵兽 → 获得种子与安全路径标记。

- 关键材料至少有安全采集与等价交换两种取得方式。
- 炼丹失败返还药渣并提供补料途径，不要求再杀一只唯一任务怪。
- 奖励按任务阶段唯一领取；地图卸载、读档、跳过演出不能重发。
- 回访可看见灵兽恢复状态与变化后的对话，不能只有一条完成提示。

### B. 残碑问阵：知识、探索与融合

三张地图各发现一段阵理 → 残星原星盘显露供能方向 → 用基础术式测试阵枢反应 → 选择解阵或清理守卫 → 开启捷径与一项融合结构。

- 不要求掌握尚未能获得的融合术才能取得该融合术。
- 碑文先描述可观察现象，再给精确机制；记录在见闻页，不要求背长文。
- 解阵路线与战斗路线都能推进；奖励侧重玩法解锁，不重复永久叠加属性。

### C. 旧台新招：原场景与新系统互相验证

经残星原山门进入落星台 → 与镇剑使交谈 → 自主选择切磋 → 观察符火、闪身穿隙与持续护身 → 结束后得到针对所用术式的短评 → 可返回准备再练。

- 第一场保持旧 Boss 核心招式节奏。变体挑战后续显式选择，不悄悄替换普通战斗。
- 非致命认输独立于死亡；重赛仅在玩家确认后重置该次切磋，不刷新世界任务。
- 可随时退出练习；正式探索主线不检查切磋胜利。
- 复练奖励以记录与操作反馈为主，避免反复切图刷无限灵气或永久数值。

## 5. 玩法系统：每套机制都要进入关卡

### 妖兽习性

| 类型 | 可见信号 | 升级为敌意 | 玩家应对与退场 |
| --- | --- | --- | --- |
| 苔角鹿 | 足迹、低头啃草、抬头警觉 | 靠近优先逃离 | 跟踪到采集点；无需击杀 |
| 岩背豕 | 扒地、低吼、巢区边界 | 先示警，持续侵入再冲撞 | 绕行、短暂引开、闪身让其撞石；不瞬移追击 |
| 暮影狼 | 声迹、灌木眼光、侧向移动 | 视线或近距声源确认目标 | 岩石遮挡、离开追击范围；重伤狼撤退 |
| 溪鳞兽（后续） | 水波、露脊、岸边蜕鳞 | 领水区受扰 | 桥面绕过、霜法创造脱离窗口；素材可捡蜕鳞 |
| 守阵傀儡（后续） | 阵线亮起、机关转向 | 节点供能且进入警戒区 | 先断阵再交战，或控制节点绕过；不算真实生命 |

“群狼协同、昼夜生态、族群繁殖”暂缓。先让单体警告、视线、领地、撤退确实可读且可测。

### 法术创造与环境应用

保留现有“最多两元素 × 弹/扇/环 × 普通/穿透/爆发”的结构与已实现的 90 种配置；90 种配置不等于 90 套独立动画。

逐步加入：术式行为 → 环境接口 → 有条件触发。不能开放任意脚本组合。

| 原创融合 | 战斗辨识 | 地图用途 | 约束 |
| --- | --- | --- | --- |
| 玉＋霜：碎冰玉刃 | 玉剑核心、棱形冰碎、减速命中 | 冻结指定浅滩 / 冷却机关 | 冻结点有明确标记与结束预警；站在临时路面结束时安全回岸 |
| 玉＋火：流焰剑 | 玉剑轮廓、橙红尾焰、短火痕 | 点燃指定灯座、清理枯藤 | 不点燃整个场景；任务物件不会被永久烧毁 |
| 玉＋雷：贯雷刃 | 保留剑形、折线跳弧、穿透点 | 激活导电阵枢 | 有目标数和距离上限，不跨图连锁 |
| 霜＋火：蒸雾术 | 冰裂后升起薄雾，区别于双色球 | 遮挡侦察或显现气流方向 | 雾不能遮住敌方伤害预警和出口 |
| 霜＋雷：霜雷锁 | 冰晶锚点连接电弧 | 短暂稳定失控机关 | Boss 控制递减；不能无限锁死 |
| 火＋雷：雷火爆 | 紧缩符核→闪光→火花扩散 | 破开指定脆岩，开放可选捷径 | 不炸毁关键 NPC；高消耗与明确前摇 |

以上地图用途、控制递减尚未实现。新增结构必须包含成本、次数上限、打断规则和可见预警；先做两种环境接口验证再扩展。由同一术式描述产生伤害事件与表现配方，预览和实战共用绘制，不在动画播放时追加伤害。

### 炼丹

- 基础一键配药保留，已掌握配方提供“稳定炼制”；非强制反应小游戏。
- 可选精炼：萃取看材料 → 调和维持可见火候带 → 凝丹选择收炉时机。
- 影响是品质或产量的有限差异，不允许失败永久丢失唯一主线材料。
- 首批三类：气血恢复、灵气恢复、环境辅助；避免几十种只改数值的丹药。
- 原有丹药数值保留为回归基线，新品质数值另表调试。
- 扣料与产出由规则事务处理，跳过演出与切换面板不重复结算。

### 阵法

- 现有一键护持阵继续可用；新“布置型阵法”作为额外类型，不替换旧按钮。
- 首个模板仅三阵旗：范围预览、有效连线、阵心确认；不能穿墙连线。
- 三种用途按阶段加入：护持、牵制、显迹。前两种进入遭遇战，第三种揭示地图线索。
- 阵旗可回收，消耗的是启动资源；退出编辑不扣费。解阵可破阵枢或改供能方向。
- 同时活动数量、范围和持续时长有硬上限；敌方预警绘在可见层。

### 傀儡

- 首批一个活跃单位，指令：跟随、守点、回收。战斗与压机关共用同一傀儡身份。
- 木核决定职责、符槽改变辅助行为；暂不做复杂装备树或自动采矿经济。
- 玩家需要保留操控容量；后续才让多单位与持续术式竞争“神识”预算，不能现在改变老护盾成本。
- 必经机关同时提供人工绕路，防止傀儡未解锁/损坏造成软锁。

### 双修 / 合修与 NPC

- 首批是明确成年 NPC、双方自愿的共同调息，不做露骨表现，不强制绑定恋爱。
- 通过对话与共同委托建立信任；拒绝或中止不惩罚主线进度。
- 玩法体现互补：一个维持节律、一个引导灵息；首批以简单配合提示和可跳过演出实现。
- 增益有限、不叠加刷取；独修、丹药仍能提供等价通关能力。
- 关系不是“交三株草立刻成为道侣”。现有药师调息只是原型，不能宣传为完整关系系统。

## 6. 视觉、动作与声音的一致性

### 美术生产分工

| 工具 | 负责 | 不能冒充完成的事项 |
| --- | --- | --- |
| ComfyUI | 地点气氛、建筑/魔兽/法器候选，保存模型、LoRA、种子、工作流 | 生成一张图不等于动画图集；不逐帧随机生成角色 |
| Blender | 固定正交镜头下搭场景体块，校准坡道、屋顶、石柱；可渲染姿态/深度参考 | 不将光滑 3D 渲染直接替换旧像素角色；首批无需重建全世界 |
| Aseprite | 统一像素网格和色板、轮廓、透明边缘、脚底锚点、关键帧、图集与时长标签 | 缩小/限色不是人工动作审查；必须看实际连续播放 |

本机已确认 Aseprite 1.3.18.6-arm64、Blender 5.2.2 LTS 可执行；ComfyUI 此前已有生成任务。**工具存在不代表三工具串联流程已验收。**

流程：需求卡 → 必要时 Blender 体块参考 → ComfyUI 小批候选 → Aseprite 修整与关键帧 → PNG/JSON → 游戏比例下验收。每个工具按需要使用，简单图标不强制绕完整流程。

### 固定风格基线

- 以旧落星台和持玉剑主角为首要比对参考；原地面投影 .62 只是现有表现基准，不能直接等同 Blender 相机角度。
- 先制作旧台、森林、溪边三种光照下的同角色样板，确认尺寸和色块密度再批量制作。
- 主角保持清晰玉剑与青玉配色；Boss 保持较大体量和赤金符箓轮廓，禁止共用主角皮肤。
- 按角色脚底、武器握点、建筑落地点导出；前景屋顶和树冠需遮挡规则，不把整张场景当不可交互背景。
- 闪身使用原图集姿态与约 .23 秒残影淡出作为回归锚点；空中残影保留高度，暂停不继续流逝。
- 新融合保留元素核心形状，再增加可读反应。伤害预警优先于烟雾、闪光、光照，提供低闪烁表现选项。
- 草地接缝、透明灰边、图集多余图标、滑步与头身跳动必须逐项检查。此前新生成素材仍为候选，不能视作已完成美术替换。

### 音乐与音效

- 音乐职责：驿站/洞府舒缓，森林疏朗，溪流空灵，遗址克制，落星台交谈与切磋分段；短暂遭遇不每次重播开头。
- 目前本地重选的主城、日常、轻松、夜晚、修炼、惊险仅为候选映射。做同场 A/B 试听后才定稿，不根据文件名保证匹配。
- 检查完整曲段及连续循环的接缝、强弱、淡入淡出和技能可听辨性。
- SoundGenerated 后续只补缺失音效：剑风、闪身、玉剑命中、符火、阵旗、傀儡机关；旧效果同步保留为基线。
- 来源音乐授权未确认，仅本机使用，不放入公开仓库、公开演示或可下载游戏包。

## 7. 分阶段交付与验收

| 阶段 | 范围 | 必须通过才扩大 |
| --- | --- | --- |
| P0 策划冻结 | 本文与研究依据；确认地图职责、旧内容保留清单、首批任务 | 设计与现状明确区分；选定代表美术/音乐样板 |
| P1 地图骨架 | 五张基础地图双向出口，落星台恢复旧构图，保存跨图状态 | 往返 20 次不重复奖励；无跨图伤害、卡地形、自动连跳；首次进入不强制开战 |
| P2 一个完整任务闭环 | 药香引路＋三种现有动物习性＋基础炼丹 | 不杀怪可完成；耗尽材料可补救；任务结果可见且唯一 |
