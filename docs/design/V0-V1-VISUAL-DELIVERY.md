# V0 / V1 首批视觉样板交付

日期：2026-10-04。对应 [优化计划](VISUAL-QUALITY-OPTIMIZATION-PLAN.md)。

**结论：技术基线已建立，听雨驿与医师的可运行视觉样板已接入。V1 的完整四方向行走动画、最终视觉批准尚未完成，因此未进入 V2 批量替换。**

## 本轮实际改变

- 听雨驿由 420×900 竖条调整为 740×720 独立区域，保留地图 ID、东侧出口、任务与采集身份；增加可走的西侧空间。
- 重新安排药庐、石庭、石路、两处药圃、池塘、灯柱与林缘。地面为低对比 Canvas 像素绘制，未声称完成全套生成式地形图集。
- 药庐实际使用 Blender 正交参考→ComfyUI 图生图→Aseprite 清稿/屋瓦细节与分层。已消除“整张道具集合当建筑”的错误。
- 松树从旧多物件素材中明确隔离单棵，离线去灰底并统一树冠色调。
- 医师不再携带白底和竹叶边框，主体约 51 像素高。ComfyUI 提供身份样板，内置图像生成补完整人物姿势，Aseprite 注册并导出 12 格图集：四方向待机/眨眼＋取药、举药观察、放回等生活姿势。
- 靠近医师时按玩家相对位置朝向玩家；远离时周期性辨药。动画与交互奖励、资源结算分离。
- 新素材采用固定透明画布/锚点与显式运行时映射，不再运行时猜背景。缺失素材有警告及可见失败回退，不把碰撞建筑变成隐形障碍。
- 建筑和树干有碰撞，池塘区分地面/飞行通行；屋后/树后遮挡时主体淡化。移动步相按实际位移推进，撞墙不继续原地迈步。
- 听雨驿单独调整初始取景与日间光照强度。原 `src/lighting.js` 没有修改，不声称新增硬件光追。

## 已执行验证

- `npm test`：旧斗法、世界规则、音乐表现、地图专项及新增听雨驿检查通过。
- 新检查覆盖西侧负坐标移动、建筑/树干/池塘碰撞、所有营地交互和出口的网格可达性、停步/暂停、四方向与工作帧索引、PNG 二值 alpha 与各格透明留边。
- 地图专项仍覆盖八个出口的规则级 20 轮往返。该测试不是人工完整游玩。
- `npm run build`：生产构建通过。
- 本机无界面 Chrome 使用正常键盘输入，检查初始庭院、辨药显示、药师交互、持续护身与御剑，并经现场出口进入雾松林再返回。不是直接调用规则伪造该次往返。
- 落星台使用界面标注的开发验收起点：检查旧场景、战前对话、拒绝切磋、护身和御剑。**没有宣称从初始地图走完整条五图路线。**
- 浏览器验收禁用外部 HTTPS 请求，场景仍能加载；没有页面异常或本地非音频资产 HTTP 错误。完整离线音频试听仍未做。
- 旧主角、Boss、云海及旧圆台/战斗特效源文件的 SHA-256 与本轮起始记录一致。

## 明确未完成

1. **NPC 行走**：方向候选中的侧面相反支撑腿不清晰，行走列未接入。医师仍是驻点 NPC，没有用站姿平移冒充走路；V1 原计划的四方向行走 16 帧仍欠缺。
2. **最终视觉批准**：当前仅为助理检查后的预览样板，用户审阅为 pending。新建筑、树冠、角色精细度仍需同场判断，不宣称已达到或超过首个 Boss 场景。
3. **素材变化**：只有一种松树；生活姿势与待机图集的细部仍有差异。屋顶虽有源层，运行时尚未做独立屋顶层，只做整体遮挡淡化。
4. **性能/体验**：未完成真实设备 30/60/120 Hz 性能测量、全路线手动游玩或长时任务平衡。
5. **后续阶段**：其他三张基础地图、美术扩批、音乐重新试听、药香任务和新增玩法未在本轮实施。

本轮没有提交或推送 GitHub，没有上传私人音乐或知识库内容；原有工作树变更保持保留。新素材仅在项目本地运行，开发期 ComfyUI/Blender/Aseprite 不成为游戏运行依赖。
